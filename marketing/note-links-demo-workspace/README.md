# Note Links Demo Workspace

Reusable DevBoard workspace for recording the notes / backlinks ad.

## How to use it

1. Open DevBoard.
2. Choose this folder as the workspace:
   `marketing/note-links-demo-workspace`
3. Open `Project Atlas`.
4. Show the backlinks / references area to demonstrate every note that mentions it.
5. Switch to the canvas page for the "when it gets bigger, map it" shot.

## Recording path

1. Start in the notes list with loose, normal-looking notes.
2. Open `Launch meeting`.
3. Point at `[[Project Atlas]]`.
4. Open `Project Atlas`.
5. Show that backlinks answer "where did this come up?"
6. End on the canvas with related notes arranged around the project.

The notes are intentionally ordinary. They should feel like something a Notepad or Apple Notes user would already have, just with links added.
