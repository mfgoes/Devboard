# 30s Spot — Note links / backlinks

**Goal:** reach people who already keep loose notes in Notepad, `.txt` files, Apple Notes, or random docs, but have never heard of PKM or Obsidian.
**Best for:** TikTok / Reels / Shorts, Bluesky productivity posts, text-note users, indie-dev launch updates.
**Tone:** simple, practical, low-jargon. "You already write notes. DevBoard helps them find each other."

---

## Hook options

- **A:** "If your notes are scattered across Notepad files, this is the bit you're missing: links between notes."
- **B:** "You don't need a whole productivity system. You need your notes to remember where they mentioned each other."
- **C:** "I got tired of searching the same folder of notes for one idea. So I built backlinks into a simple notes app."

## Beats

| Time | What you show | Voiceover / overlay |
|---|---|---|
| 0-3s | Show a sidebar or folder with loose notes: `ideas`, `meeting-notes`, `research`, `todo`. | **Overlay:** "You wrote it down. Somewhere." |
| 3-7s | Open a note and type `[[Project Atlas]]` inside a sentence. | **VO:** "Type a note name in double brackets." |
| 7-11s | Click the link and open the connected note. | **Overlay:** "Now the notes are connected." |
| 11-16s | Show the backlinks / references area for `Project Atlas`, with multiple source notes listed. | **VO:** "Backlinks are just automatic 'mentioned in' lists." |
| 16-21s | Click a backlink and jump back to the exact source note. | **Overlay:** "Jump back to context instantly." |
| 21-25s | Show the workspace folder on disk with local Markdown files. | **Overlay:** "Still just files in your folder." |
| 25-30s | Cut to the canvas with the same project mapped visually, then the note-links landing page CTA. | **VO:** "When it gets bigger, map it. DevBoard. Try it free." |
